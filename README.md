# 写作助手 · 专属写作模型项目

> 一支**只做写作**的笔，不做其他任何事。
> 这是张义的个人项目：先有好用的写作工作流（v1），再攒蒸馏数据（v2），最后在 RTX 3090 上微调出真正属于自己的写作模型（v3）。

## 在线体验

开启 GitHub Pages 后访问：`https://Zq1953298586.github.io/writing-assistant/`

也可以直接双击打开 `index.html`，或在目录里跑 `python3 -m http.server 8000` 后访问 `http://127.0.0.1:8000`。

## v1 网页版：四个写作模式

- **续写**：给前文，沿着人物/视角/语气写下去
- **润色改写**：草稿→大师版，不改变原意
- **风格仿写**：按范文的风格 DNA 改写你的草稿
- **批评家**：先当编辑挑毛病，再动手改
- **我的风格档案**：存你的文风偏好，每次自动带上（本仓库版本用浏览器本地存储，刷新不丢）
- **模板小说**：上传 TXT/Markdown 小说，写作时自动抽代表段落让模型学笔法（只学叙事视角/句式/节奏/对话，不照搬人物设定情节）

## 连接本地模型（重要说明）

页面设置区可填 LM Studio（`http://localhost:1234/v1`）或 Ollama 地址直连本地模型。
**但请注意**：从任何 `https` 网页（含 GitHub Pages）直接调用 `http://localhost:1234`
会被浏览器安全策略拦截——这是浏览器厂商的规定，不是代码问题。
所以推荐用法：

1. **主用"复制指令"模式**：点一下复制完整写作指令，粘贴到 LM Studio 对话框里用；
2. 在本机用 `http://` 打开页面时（如 `python3 -m http.server`），直连本地模型可用；
3. v3 专属模型训好后接云端 API，直连问题自然消失。

## 目录结构

```
index.html            v1 网页版（单文件，可直接部署到 GitHub Pages）
docs/                 写作任务分类标准 v1.0、蒸馏数据集规范与示例
scripts/              蒸馏数据批量生成脚本（连本地 LM Studio 批量生产训练数据）
training/             LoRA 微调套件（Unsloth 训练脚本 + 小白指南 + 评测方案）
qa/                   测试工具（mock 模型接口、静态检查、测试用小说、QA 日志）
.github/workflows/   CI：每次推送自动跑静态检查
```

## 数据红线

训练数据只允许：蒸馏数据 + 自己的语料，八类纯写作任务。
不混入通用问答、代码、闲聊——否则"只做写作"的定位会被冲淡。
